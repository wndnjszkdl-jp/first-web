3단계만 거치면 멋진 블로그 서평과 에세이가 완성됩니다.

1

책 & 키워드 입력

읽은 책의 제목이나 인상 깊었던 구절, 혹은 떠오른 감정 단어를 자유롭게 입력합니다.

2

감성 톤 & 플랫폼 선택

따뜻한 위로, 깊은 사유, 유쾌한 소통 등 원하는 분위기와 네이버 블로그/브런치 등 목적을 선택합니다.

3

AI 초안 다듬기 & 발행

AI 코칭으로 생성된 글을 복사하거나 PDF/TXT 파일로 저장하고, 마이 서재나 블로그에 발행하세요.

자주 묻는 질문 (FAQ)

별 헤는 밤 서비스에 대해 궁금한 점을 확인하세요.

네, 가능합니다! API 키가 설정되지 않은 경우에도 '별 헤는 밤'의 자체 감성 템플릿 시뮬레이션 알고리즘이 가동되어 풍부한 독서 에세이 초안을 즉시 생성해 드립니다. 본인만의 Gemini API 키를 입력하면 더욱 정교한 맞춤 실시간 글을 얻을 수 있습니다.
생성된 글의 모든 소유권과 편집권은 사용자에게 있습니다. 네이버 블로그, 브런치, 개인 서재 등 원하시는 곳 어디에나 자유롭게 수정하여 발행하셔도 좋습니다.
에세이가 생성된 후 우측 상단의 [서재 저장] 버튼을 누르면 마이 서재 저장함에 추가됩니다. 로그인 상태에서 이용하시면 마이페이지(/mypage)에서 저장된 목록을 확인하실 수 있습니다.
입력받은 API 키는 서버나 외부 DB에 저장되지 않고, 사용자의 웹 브라우저 로컬 세션에만 잠시 보관되어 안전합니다.
